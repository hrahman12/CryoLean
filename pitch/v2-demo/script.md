# CryoLean v2 · Demo-first: 60-second talk track

**Slide 1 · Title (about 15 s).** This is CryoLean. Before you book time on a cryostat, you want to know one thing: can
this machine run my experiment? CryoLean gives one honest answer, and there are only three: requirements met, need more
information, or does not meet.

**Slide 2 · Three answers (about 25 s).** Three real checks. Mars-rover sensors in a Tinius Olsen chamber: met, because
the chamber covers minus 150 to plus 600 degrees. Whole 300 millimetre wafers on a Bluefors fridge: the wafer size is
unconfirmed, so Lean waits instead of guessing. A protein crystal on a Lake Shore CCS-800: no liquid nitrogen, so it
does not meet.

**Slide 3 · Live demo (about 20 s).** Now you pick. Choose from 20 industries and 220 cryostat configurations. Lean
shows the first stage where the run fails, and offers only fixes it has passed. Untick a need and the answer turns
amber. Every answer is a precomputed Lean outcome. Let's go live.
