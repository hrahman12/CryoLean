# Integration audit

The same CryoLeanAPI, compiled Lean checker, serializer, source validation and
Z3 solver serve desktop and browser transports. No Lean theorem logic changed.

Live checks call check_compatibility. A post-check get_verified_repairs search
keeps the exact reviewed requirements and searches model-declared adjustable
parameters plus actual catalog configurations. Z3 ranks/proposes; Lean checks
every candidate that can be recommended. FAIL and UNKNOWN candidates are
excluded from the fixes array. Hypothetical installations and requirement
relaxations are excluded. A finite unsuccessful search returns exactly
No verified solution found, with its searched scope and discarded counts.

Each fix includes exact parameter quantities, configuration ID, evaluated Lean
documents, input hash, catalog fingerprint, source/binary hash, checks, theorem
metadata and evidence references. Display strings never become solver inputs.

Apply Fix retrieves the server-held candidate, compares the fresh catalog and
input fingerprints and checker hash, runs the normal Lean pipeline again,
checks that the reproduced input hash matches the advertised PASS, and stores
a separate revised result. It refuses changed inputs rather than forcing a
positive result. Original requirements and the original result remain intact.

The reducer invalidates results on input changes and ignores late responses.
Mode switches retain live state. Recorded results are held in a separate
playback controller and never dispatched as new live evaluations.

The catalog is exported through canonical backend reads on every root build.
204 profiles and 220 configurations match the backend IDs. Industry relevance
controls presentation only; each pair receives an independent Lean result.

39 source-guided instrument geometry families, 41 measurement mechanisms and
60 researched internal-construction descriptors drive the WebGL scenes. Actual
configuration identity, installed probe arms, wiring, windows, sourced outer
aspect and stage construction change the presentation. Geometry cannot supply
an unknown capability or assert that an optional accessory is installed.

The 180-pair recorded matrix is in docs/coverage and frontend/public/coverage.
It is explicitly separated from fresh verification of a visitor's inputs.
