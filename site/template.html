    How the physics becomes LeanFrom a datasheet sentence to a proved verdict, using the graphene example · click to show or hide
    
    
      
    1
    Two sentences
    The experiment's procedure says it needs a magnetic field of at least 12 T. The Cryogenic Ltd datasheet says its magnet goes up to 9 T. Each fact keeps a link to the document it came from.
    
      
    2
    Exact numbers with units
    Python turns each number into an exact fraction in SI units, with no rounding and no decimals, and records its unit as powers of the seven SI base units. Tesla is kg·s⁻²·A⁻¹.
    
        
    {"num": 12, "den": 1, "dim": {"kg": 1, "s": -2, "A": -1}}   // the 12 T requirement
{"num":  9, "den": 1, "dim": {"kg": 1, "s": -2, "A": -1}}   // the 9 T magnet
    
      
    3
    Lean types
    In Lean the requirement becomes a Constraint and the machine's spec a CapValue (lean/CryoLean/Model.lean).
    
        
    structure Quantity where
  val : Q        -- exact rational num / den
  dim : Dim      -- exponents of K, m, kg, s, A, mol, cd

Constraint.atLeast ⟨⟨12, 1⟩, {kg := 1, s := -2, A := -1}⟩   -- needs at least 12 T
CapValue.max      ⟨⟨9, 1⟩,  {kg := 1, s := -2, A := -1}⟩   -- documented maximum 9 T
    
      
    4
    Lean decides
    The checker compares the two only if their units match, using whole-number cross-multiplication, so it can't make a rounding error (lean/CryoLean/Checker.lean, Num.lean).
    
        
    def Q.le (a b : Q) : Prop := a.num * (b.den : Int) ≤ b.num * (a.den : Int)

def checkValue : Constraint → CapValue → Outcome
  | .atLeast q, .max m =>
      if m.dim = q.dim then (if Q.le q.val m.val then .pass else .fail) else .unsupported
  ...
-- 12 * 1 ≤ 9 * 1 is false  →  .fail  →  verdict: does not meet requirements
    
      
    5
    Proved, not just tested
    A theorem says every .pass really means the physical requirement holds. Lean checks this proof for every case, so a pass can't be wrong (lean/CryoLean/Soundness.lean).
    
        
    theorem checkValue_pass_sound {k : Constraint} {v : CapValue}
    (h : checkValue k v = .pass) : ValueMeets k v
    
      
    6
    Instant answers on this page
    Lean already decided every requirement at each documented limit of every machine, and in every gap between limits. When you type a value, the page looks up which gap it falls in and shows Lean's answer for it. A missing spec stays .unknown, which is why the nitrogen-tank example says Need more information instead of guessing.
