The 180 featured pairings

20 industries × 3 experiments × 3 machines. Every square is a verdict the Lean 4 checker already returned. Nothing on this page is recomputed or recolored.

How the green went up, honestly

  • Best-match machines: for each industry, the 3 machines (out of all 220) that Lean passes most often for its 3 experiments. Lean already checked every experiment against every machine, so this just features the right ones.
  • The ceiling is real: some experiments pass on no machine in the catalog (shown as 0 anywhere), so a few red squares can't turn green without new machines or newly sourced specs.
  • Verdicts are at each experiment's default values. Source: site/lattice.json, Lean source hash .
